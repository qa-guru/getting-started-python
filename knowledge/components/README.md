# Каталог переиспользуемого кода

- [Вспомогательные функции](utils.md) — генерация и загрузка тестовых данных.
- [Фикстуры](fixtures.md) — подготовка данных для тестов.
- [Модели и исключения](models.md) — структуры данных и общие ошибки.
- [Константы](consts.md) — фиксированные тестовые данные и текущие имена настроек.
- [Инфраструктура](infrastructure.md) — браузер, ожидания и отчётность.

Перед написанием нового компонента прочитай подходящий раздел и проверь
существующие реализации в коде. После изменения компонента обнови его запись:
имя, путь импорта, назначение и пример использования.

Оглавление содержит только ссылки и краткое описание разделов. Записи компонентов
хранятся в одном тематическом файле без дублирования. При разрастании раздела
разделяй его по предметным областям и обновляй ссылки в этом оглавлении.
