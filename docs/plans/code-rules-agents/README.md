# Промпты для агентов

Каждый файл — самостоятельный промпт: передай его содержимое агенту,
у которого есть доступ к актуальному рабочему дереву проекта.

| Порядок | Промпт | Результат |
| --- | --- | --- |
| 1 | [Общие компоненты](01-components.md) | Перенос helpers и обновление импортов |
| 2 | [Тестовые данные](02-test-data.md) | Константы, изоляция и жизненный цикл данных |
| 3 | [Allure](03-allure.md) | Шаги, метаданные и диагностика |
| 4 | [Ошибки](04-errors.md) | Освобождение ресурсов и проверки сбоев |
| 5 | [Итоговая проверка](05-verification.md) | Повторный аудит и отчёт |

Запускай агентов последовательно: `1 → 2 → 3 → 4 → 5`. Они изменяют общие
файлы, импорты и каталог; промпты не рассчитаны на одновременное выполнение.
Перед началом следующего этапа передай ему итоговый отчёт предыдущего агента
и убедись, что изменения доступны в его рабочем дереве. Если используются
разные checkout, сначала перенеси результат предыдущего этапа.

При блокирующем дефекте реализации сначала заверши текущую фазу. Если
недоступна внешняя проверка (например, стенд), её можно передать финальному
агенту как явно указанную незавершённую проверку.

Исходный [план по фазам](../code-rules-compliance.md) остаётся источником
объёма работ. Промпты подготовлены; агенты ещё не запущены.
